## 数据意图

数据意图层把「搜索效率低」这一模糊判断转成形式化验证：界定对象、给出操作定义、建立指标、提出可证伪命题、指定验证方法，并登记验证结论。本层不涉及数据表、字段、代码与工具。

### 形式化对象

| 对象 | 记号 | 说明 |
|:--|:--|:--|
| 会话 | s | 一次完整交互 |
| 轨迹 | τ = (a₁, a₂, …) | 会话内的动作序列 |
| 动作 | a | 一次工具调用 |
| 搜索事件 | e | τ 中被判定为搜索的动作 |
| 查询 | q | 搜索事件的输入 |
| 结果 | r | 搜索事件的返回 |

变量与随机变量：查询 q；结果特征——条数 n、是否为空 ∅、是否错误 ϵ、字符数 ℓ、是否可结构化 ρ；行为特征——连续次序 k、结果后首个非搜索动作、是否行动前再搜；时延 Δt。任务目标 g 与工具预算 B 作为外部给定。

### 操作定义

- **搜索判定**：一次工具调用满足任一条件即计为搜索——工具名 ∈ 搜索工具集（search_files、session_search、memory_search、grep、glob、find、find_path、list_directory、search）；或工具为 shell 类（terminal、bash、shell、run_terminal_cmd）且命令行匹配搜索动词（grep、rg、ripgrep、find、fd、locate、ag、ack、ls、tree、which、whereis）。
- **查询漂移** drift(q, g)：查询与任务目标的语义相似度低于阈值 δ。
- **结果被消费** consume(e)：结果之后的首个非搜索动作读用了该结果（读文件、引用等）。
- **结果未利用**：结果被消费为假。
- **过度搜索**：单会话或单目标内的搜索次数超过工具预算 B。
- **有效命中率**：结果非空、非错误且被消费的搜索 ÷ 搜索总数。

### 指标

分母默认为搜索总数，空结果率除外。

| 指标 | 定义 |
|:--|:--|
| 空结果率 | 结果条数为 0 的搜索 ÷ 能解析出结果条数的搜索 |
| 错误率 | 返回错误的搜索 ÷ 搜索总数 |
| 结构化结果占比 | 结果可解析为 JSON 的搜索 ÷ 搜索总数 |
| 结果体量 | 结果字符数 ℓ 的中位数、P90、最大值 |
| 过载率 | ℓ 不小于阈值（默认 8000）的搜索 ÷ 搜索总数 |
| 连续搜索率 | 连续次序 k > 0 的搜索 ÷ 搜索总数 |
| 搜完又搜未行动率 | 在调用非搜索工具前再次搜索的搜索 ÷ 搜索总数 |
| 会话内重复查询率 | 同一会话内归一化查询出现两次及以上的搜索 ÷ 搜索总数 |
| 搜索后读文件率 | 结果之后首个动作是读文件的搜索 ÷ 搜索总数 |
| 延迟中位数 | 结果时间戳与调用时间戳之差的中位数 |

聚合维度：全局、按来源、按会话三层，便于把结论下钻到具体来源与会话。

### 命题与假设

失败 fail(s) 定义为会话未达到目标动作。

| 假设 | 内容 | 可证伪条件 |
|:--|:--|:--|
| H1 | 空结果率高的会话更易失败 | 空结果率与任务失败呈负相关或无关 |
| H2 | 连续搜索与结果未被消费正相关 | 连续搜索率与未消费率不相关 |
| H3 | 结果过载与有效命中率负相关 | 过载率与有效命中率不相关或正相关 |

### 因果图

```
prompt_version → query_drift → result_unused → task_fail
retrieval_env  → query_drift
tool_budget    → result_unused
```

混杂变量：任务类型、来源、会话长度。H1–H3 目前是相关命题，因果方向须经识别策略确认（见「验证方法」）。

### 约束与不变量

- 搜索次数 ≤ 工具预算 B。
- 查询与任务目标的相似度 ≥ δ，否则记为漂移。
- 结果引用覆盖 ≥ γ。

### 验证方法

- 假设：零假设 H0 与备择假设 H1–H3。
- 统计检验：比例用两比例 z 检验，相关用 Spearman 或卡方；报告效应量与置信区间。
- 样本量：按基线效应量估算，控制 I 类错误。
- 偏差控制：按来源与任务类型分层，避免辛普森悖论。
- 因果识别：可行时用提示词版本的 A/B，或用反事实/断点回归；不可识别时只报告相关。
