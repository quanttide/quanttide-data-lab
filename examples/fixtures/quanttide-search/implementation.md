## 数据实现

数据实现层给出一条可复现的工程路径。技术栈为 Python 与 polars，中间产物用 Parquet，同一条命令行工具贯穿采集、清洗、分析与报告。

### 技术栈

- 语言：Python。
- 数据处理：polars。
- 中间产物：Parquet。
- 报告：Markdown。

### 数据管道

按「数据规格」的流程步骤实现采集、清洗、分析、验证、报告五步。每步的输入、处理规则与产物以数据规格为准，本层只写具体代码与工具。

### 命令行入口

复现命令依次为：

1. `load`：采集。
2. `clean`：清洗。
3. `analyze`：分析并产出指标 JSON 与报告 Markdown。
4. `verify`：对 H1–H3 执行统计检验并落盘检验结果。

### 质量校验脚本

- 采集后核对 manifest 行数。
- 清洗后核对四表行数与搜索计数。
- 分析后核对报告与 JSON 数值一致。
- 验证后核对检验结果与指标口径一致。

### 版本管理

数据、代码、报告各自带上版本与时间戳。

### 执行验证

对 H1–H3 按「数据意图」的验证方法执行：计算检验统计量、效应量与置信区间；可行时做因果识别（提示词版本 A/B 或反事实），不可识别则只报相关。检验结论与原始指标一并落盘。

### 报告生成

报告固定包含：总览、按来源、结果质量、结果体量、行为模式、搜索后首个动作分布、每会话摘要（截断只展示前若干名），末尾附诊断与证据强度。报告与指标 JSON 一并写出，两者数值一致；任何结论都必须回指到具体指标与命题，不得由模型自由生成。
